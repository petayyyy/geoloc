## Цель

Реализовать 12 сценариев из `../testing/04-level-e-isaac.md` §4 и механизм внесения отказов.

Два из них — **S-04 и S-05** — блокирующие: провал любого означает «в поле не выходим».

## Что реализовать

1. **Механизм fault injection:** узел-прокси между `geoloc_integrity` и `geoloc_fusion` (либо между `geoloc_mavlink` и MAVROS), подменяющий и искажающий сообщения по декларативному YAML-сценарию.

```yaml
# scenarios/S-05-consistent-false-fixes.yaml
seed: 42
trigger: {type: distance, value_m: 1500}
injections:
  - type: false_fix
    count: 3
    interval_s: 1.0
    offset: {east: 120.0, north: -90.0, yaw_deg: 2.5}
    fake_quality:                  # правдоподобные метрики — самый злой вариант
      n_inliers: 84
      covisibility: 0.41
      peak_ratio: 1.9
      residual_rms_px: 0.8
expect:
  accepted_false_fixes: 0
  max_position_error_growth_m: 30.0
```

2. **Типы инъекций:** пропадание фиксов, ложный фикс, окклюзия камеры, деградация лидара, скачок/дрейф AGL, шум и bias IMU, задержки и джиттер, разрыв tf.
3. **Двенадцать сценариев** S-01…S-12 по спецификации, каждый с критерием прохождения.
4. **Раннер:** `make sim-scenario ID=S-04 SEED=42`, детерминированный, headless, с автоматической проверкой критериев.
5. **Отчёт:** таблица «сценарий × прошёл/не прошёл × метрики», трасса каждого провала, видео пролёта.
6. **Интеграция в CI:** ночной прогон S-01…S-07, S-09, S-10 на GPU-раннере; полный набор — перед контрольными точками.

## Definition of Done

- [ ] Все 12 сценариев реализованы и запускаются одной командой
- [ ] **S-04 и S-05 проходят** — блокирующее условие

- [ ] Механизм инъекций покрывает все восемь типов отказов

## Подводные камни

- **S-05 — самый важный тест проекта.** Три взаимно согласованных ложных фикса с правдоподобными метриками качества воспроизводят именно то, что происходит на периодических структурах в реальности. Проверка согласованности их не поймает — они согласованы. Поймать может только `peak_ratio` и χ²-гейт по приору. Если S-05 проваливается — проблема в T22, и её надо решать, а не ослаблять сценарий.
- **Соблазн смягчить блокирующий критерий** возникает ровно тогда, когда сроки поджимают, а сценарий не проходит. Это худший момент для такого решения. Критерий `accepted_false_fixes: 0` не подлежит обсуждению.
- Инъекция должна быть **правдоподобной**. Ложный фикс с `n_inliers=5` отвергнет любой гейт — такой тест ничего не проверяет. Значения `fake_quality` подбирать так, чтобы они проходили все гейты, кроме тех, что должны сработать.
- Isaac-прогоны долгие. Держать длительность сценариев минимально достаточной, иначе ночной CI не уложится в ночь.
