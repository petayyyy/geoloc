## Цель

Расширить OrthoSim так, чтобы он тестировал **весь** пайплайн, а не только матчер: от облака точек до SE(2). Ключевая цель — проверить поведение при **дефиците лидарного покрытия**, который на 100–150 м AGL составляет около 30% ширины кадра.

## Что реализовать

### 1. Синтез облака Livox Avia

| Свойство | Модель |
|---|---|
| Паттерн | Non-repetitive розетка Avia; табличный паттерн либо аппроксимация Лиссажу |
| **FOV** | **70.4° × 77.2° — соблюдать строго.** Это ядро задачи |
| Дальность | до 190 м @ 10% отражения; вероятность возврата падает с дальностью и отражательной способностью |
| Частота | ~240 000 точек/с |
| Шум | σ ≈ 2 см + пропорциональная составляющая |
| **Motion distortion** | Точки генерируются вдоль реальной траектории за интервал накопления — **иначе deskew не тестируется** |
| Отказы | Вода → нет возврата; тёмные и зеркальные поверхности → пониженная вероятность |

Выход — `livox_ros_driver2/CustomMsg`, чтобы пайплайн не отличал от реального.

### 2. Полноценный DSM и тени

- Рендер запроса через реальный DSM (из OrthoLoC либо синтезированный из OSM-footprints экструзией) — даёт параллакс зданий;
- направленные тени ray-cast'ом по DSM;
- свип высоты солнца 10° / 30° / 60° / 80°.

### 3. Обязательные тест-кейсы, которых иначе нигде не будет

| ID | Что проверяет | Ожидание |
|---|---|---|
| **A-DSM-01** | Доля патча с лидарным покрытием при AGL 100 / 125 / 150 м | ~70%. Если карта уверенности показывает иное — она врёт |
| **A-DSM-02** | Стык «лидарный DSM ↔ Copernicus» | Скачок высоты на границе не порождает артефакт в true-ortho |
| **A-DSM-03** | Deskew | Без deskew ошибка растёт с ростом скорости; с deskew — не растёт |
| **A-DSM-04** | Взвешивание по уверенности | Инлаеры в зоне DEM влияют на оценку слабее, чем в лидарной зоне |
| **A-DSM-05** | Параллакс зданий | В городе true-ortho по DSM даёт заметно меньшую ошибку, чем плоскостное допущение |

## Definition of Done

- [ ] Синтезированное облако подаётся в FAST-LIVO2 и обрабатывается без ошибок
- [ ] FOV и дальность соответствуют Avia, проверено измерением пятна
- [ ] Motion distortion присутствует и отключаема (для теста A-DSM-03)
- [ ] Все пять тест-кейсов A-DSM-* реализованы и проходят
- [ ] Свип по углу солнца работает, тени физически правдоподобны
- [ ] Время генерации не выросло настолько, чтобы выбить `regression` из 15 минут

## Тесты

| ID | Уровень | Что проверяет | Критерий |
|---|---|---|---|
| T11-U-01 | 0 | Геометрия FOV | Пятно облака на плоскости при AGL 100 м = 141 × 160 м ± 2% |
| T11-U-02 | 0 | Плотность точек | ~240 kpts/s ± 5% |
| T11-U-03 | 0 | Motion distortion | При отключённом deskew облако от движущейся платформы «размазано» предсказуемо |
| T11-U-04 | 0 | Отказ на воде | Область воды в DSM → отсутствие возвратов |
| T11-A-01..05 | A | Кейсы A-DSM-01..05 | Согласно таблице выше |

## Подводные камни

- **Дефицит покрытия — не баг симулятора, а свойство железа.** Соблазн «расширить FOV, чтобы тесты проходили» надо задавить: именно этот дефицит и нужно оттестировать.
- Синтетическое облако выглядит слишком чисто. FAST-LIVO2 на нём будет работать лучше, чем в реальности — **не использовать OrthoSim для оценки одометрии**, для этого есть уровень B.
- Экструзия OSM-footprints даёт коробки без крыш нужной формы. Для проверки параллакса этого достаточно, для оценки абсолютной точности — нет.
