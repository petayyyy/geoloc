## Цель

Загрузить и нормализовать датасеты уровня B. Начинать в первый день: объём сотни ГБ, загрузка идёт фоном, пока делается всё остальное.

## Датасеты и приоритет

| Приоритет | Датасет | Зачем |
|---|---|---|
| 1 | **MARS-LVIG** | Livox Avia + global-shutter камера (hw-sync 10 Гц) + IMU + RTK, 80–130 м, до 7.148 км. Ровно наша конфигурация |
| 2 | **OrthoLoC** | UAV-снимки + DOP 5 см + DSM + RTK/GCP. Для матчинга true-ortho ↔ орто и валидации AdHoP |
| 3 | **AnyVisLoc / UAV-AVL Benchmark** | 20 077 снимков, 24 сцены, аэро- и спутниковая подложка. Сравнение Tier1/Tier2 |
| 4 | **UAVScenes** | MARS-LVIG + семантика + 6-DoF позы. Для T20 |
| 5 | UAV-VisLoc, VPAIR | Дополнительные сцены |

## Что реализовать

1. Скрипты загрузки с докачкой и проверкой контрольных сумм.
2. **Нормализация в единый формат:** ROS 2 bag с топиками по `../03-interfaces.md` §2, чтобы реплей шёл через боевой граф без адаптеров.
   - `livox_ros_driver2/CustomMsg` для лидара — не `PointCloud2`, иначе FAST-LIVO2 будет работать иначе, чем в поле;
   - таймстампы — источника, не приёма.
3. **Извлечение ground truth:** RTK → траектория в UTM; курс из направления движения на прямых участках либо из 6-DoF UAVScenes.
4. **Нарезка на прогоны** по `../testing/03-level-b-replay.md` §4: `micro`, `convergence`, `terrain`, `full`.
5. **Каталог** — YAML с описанием каждой последовательности: длина, высота, скорость, класс местности, наличие GT.

## Definition of Done

- [ ] MARS-LVIG загружен, конвертирован в bag, воспроизводится `ros2 bag play`
- [ ] FAST-LIVO2 отрабатывает на конвертированном bag с тем же результатом, что на исходном
- [ ] GT извлечён, траектории в UTM, курс определён
- [ ] Нарезки созданы, каталог заполнен
- [ ] Контрольные суммы проверяются, повторный запуск не перекачивает

## Подводные камни

- **Формат сообщения лидара критичен.** FAST-LIVO2 использует поле времени каждой точки для deskew. Конвертация в обычный `PointCloud2` его теряет и меняет поведение одометрии — тест T08-I-01 существует именно для того, чтобы это поймать.
- RTK-траектория MARS-LVIG в WGS84; наша опорная точка задаётся отдельно. Не смешивать системы.
- Курс из направления движения врёт на разворотах и при сносе. Использовать только прямые участки со скоростью выше порога.
- Объём: заложить место заранее. Полный MARS-LVIG — сотни ГБ.
