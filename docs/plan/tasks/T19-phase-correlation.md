## Цель

Резервный канал матчинга, работающий там, где точечные признаки не находятся: слабая текстура, сильная сезонная или радиометрическая разница, размытие.

## Почему именно этот метод

Фазовая корреляция по **ориентации градиента** (а не по яркости) устойчива к монотонным изменениям освещённости и к разнице радиометрии между провайдерами — то есть ровно к тому, что убивает точечные признаки при кросс-доменном матчинге. Она не даёт разреженных соответствий, зато даёт глобальный сдвиг целиком, и делает это дёшево (~20 мс).

Она не заменяет XFeat: точность ниже (5–15 м против 3–6 м), курс грубее (1–3°). Её задача — **не дать ковариации расти неограниченно**, когда основной канал молчит.

## Что реализовать

1. **Предобработка:** градиент по Соболю → ориентация градиента → окно (Ханна) для подавления краевых эффектов.
2. **Log-polar FFT** для оценки поворота и масштаба: преобразование спектров в лог-полярные координаты, фазовая корреляция → `Δψ` и масштаб.
   - Масштаб у нас известен, поэтому оценённый масштаб используется как **проверка**, а не как результат: сильное расхождение с известным = плохой матч.
3. **Фазовая корреляция** на скомпенсированной по повороту паре → `Δx, Δy`.
4. **Метрики качества** для этого канала, отображённые в тот же контракт `SE2Fix`:
   - `peak_ratio` — отношение главного пика корреляции ко второму;
   - острота пика (ширина на полувысоте);
   - `n_inliers` / `covisibility` — не имеют прямого смысла, заполняются эквивалентами или помечаются как неприменимые.
5. **Учёт карты уверенности:** зоны с нулевой уверенностью маскируются до FFT.

## Definition of Done

- [ ] Канал работает, латентность ≤20 мс на плате
- [ ] Метрики качества заполняются, `peak_ratio` осмысленно различает хороший и плохой матч
- [ ] На сценах со слабой текстурой даёт результат там, где XFeat молчит
- [ ] Точность на `regression`: `A@20` ≥ 40% (ниже основного канала — это нормально)
- [ ] `IFR` канала измерен отдельно; при превышении 1% канал не используется для `fix_type=3`

## Подводные камни

- **Фазовая корреляция очень уверенно ошибается на периодических структурах.** На сельхозсетке она даст острый пик, сдвинутый ровно на период. `peak_ratio` здесь единственная защита, и его надо считать по **пространственно отделённым** пикам, а не по соседним отсчётам одного пика.
- Окно Ханна обязательно: без него краевые эффекты FFT дают ложный пик в центре.
- Log-polar преобразование теряет точность на краях спектра. Оценка поворота будет грубее оценки сдвига — это ожидаемо, отражать в ковариации.
- Канал должен честно сообщать, что он резервный: `channel = 1` в `SE2Fix`, и T22 обязан применять к нему более строгие пороги.
