## Цель

Бортовой узел, выдающий окно подложки по запросу приорного положения, с кэшированием дескрипторов. Он же — единственная точка доступа к DEM и семантике.

Ключевая идея архитектуры: **приорное окно из ковариации заменяет retrieval-сеть.** Ковариация фьюжна даёт радиус R; матчим только внутри него. Это снимает главную причину, по которой в литературе вводят VPR, и экономит порядок вычислений.

## Что реализовать

1. **Загрузка `.geopack`** через mmap, ленивое чтение тайлов COG.
2. **Сервис `MapWindow.srv`** (см. `../03-interfaces.md` §1.4): центр, радиус, GSD → окно растра + опционально дескрипторы.
3. **Выбор уровня пирамиды** по запрошенному GSD.
4. **Кэш дескрипторов карты:**
   - дескрипторы считаются для текущего окна и переиспользуются;
   - пересчёт, когда центр окна сместился на **>30% размера окна** либо изменился запрошенный GSD;
   - это даёт амортизированные ~8 мс/кадр вместо полного пересчёта.
5. **Предзагрузка по ходу движения:** упреждающая подкачка тайлов по направлению скорости, чтобы не ловить задержку диска в контуре.
6. **Доступ к DEM и семантике** тем же интерфейсом, с той же геопривязкой.

## Ключевые решения

| Решение | Значение | Обоснование |
|---|---|---|
| Предвычисление дескрипторов офлайн | **Нет**, только бортовой кэш | Привязывает пакет карты к версии модели и раздувает его; выигрыш ~8 мс амортизированно не окупает |
| Хранение окна | uint8 grayscale + отдельная маска валидности | Матчер работает по яркости |
| Порог пересчёта кэша | 30% размера окна | Компромисс между частотой пересчёта и актуальностью |
| Радиус окна | Из ковариации: `R = k·√(σ_e² + σ_n²) + margin`, `k ≈ 3` | 3σ покрывает 99.7% |

## Definition of Done

- [ ] Сервис отвечает за ≤20 мс на окно 600×600 px без дескрипторов, ≤40 мс с дескрипторами (на плате)
- [ ] Кэш даёт попадание ≥85% при типичной скорости 10 м/с и такте 2 Гц
- [ ] Предзагрузка скрывает задержку диска: p95 времени ответа не выше p50 более чем в 2 раза
- [ ] Память узла ≤ 200 МБ при работе с пакетом 10 × 2 км
- [ ] Маска валидности корректно передаётся вместе с окном

## Подводные камни

- Запрос окна за границей пакета миссии — штатная ситуация при уходе с маршрута, а не исключение. Обрабатывать явно.
- Кэш дескрипторов должен инвалидироваться и при смене версии модели матчера, иначе после обновления XFeat получим тихую несовместимость.
- mmap на NVMe быстр, но первое обращение к холодному тайлу — десятки миллисекунд. Отсюда требование предзагрузки.
