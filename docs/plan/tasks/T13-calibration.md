## Цель

Получить и валидировать калибровку связки Livox Avia + камера + IMU. Это начало критического пути: всё, что дальше, строится на этих числах.

## Требования (из `../01-requirements.md` §6)

| ID | Требование |
|---|---|
| CAL-01 | Интринсики камеры: RMS репроекции ≤ 0.3 px |
| CAL-02 | Экстринсики камера ↔ лидар: ≤ 0.2° / 2 см |
| CAL-03 | Экстринсики IMU ↔ лидар: из конфигурации Avia + онлайн-уточнение в FAST-LIVO2 |
| CAL-04 | Временная синхронизация: ≤ 5 мс, предпочтительно аппаратный триггер |
| CAL-05 | Повторяется после любой разборки узла |

## Что реализовать

1. **Интринсики камеры.** Стандартная процедура по мишени. Модель дисторсии выбрать по остаточной ошибке; при HFOV 90° обычной радиально-тангенциальной достаточно, но проверить остатки на краях кадра.
2. **Экстринсики камера ↔ лидар.** Целевой или бесцелевой метод (взаимная информация между интенсивностью лидара и яркостью изображения). Валидация — проекция облака на изображение: рёбра облака должны ложиться на рёбра изображения.
3. **Временная синхронизация.**
   - Предпочтительно: аппаратный триггер камеры → `CAMERA_TRIGGER` в Pixhawk;
   - минимум: оценка постоянного смещения по корреляции угловых скоростей (из оптического потока и из IMU);
   - измерить не только смещение, но и **джиттер**.
4. **Процедура и оснастка.** Задокументировать так, чтобы калибровку мог повторить не автор. Она будет повторяться после каждой переборки.
5. **Формат хранения** калибровки — в конфиге миссии, с версией и датой.

## Definition of Done

- [ ] Интринсики: RMS репроекции ≤ 0.3 px, остатки на краях без систематики
- [ ] Экстринсики камера ↔ лидар: ошибка ≤ 0.2° / 2 см, подтверждена проекцией облака
- [ ] Смещение синхронизации измерено, ≤ 5 мс; джиттер измерен и задокументирован
- [ ] Процедура задокументирована пошагово, воспроизведена вторым человеком
- [ ] Калибровка загружается в граф, статические tf публикуются

## Подводные камни

- **Ошибка синхронизации маскируется под ошибку экстринсиков.** На движущейся платформе постоянное временное смещение выглядит как постоянный угловой сдвиг. Калибровать в статике или явно разделять эффекты.
- **Вибрация меняет экстринсики.** Калибровка на столе и калибровка на аппарате с работающими моторами — разные вещи. Это стык с T35; закладывать проверку после монтажа.
- Livox Avia бесцелевую калибровку по взаимной информации проходит хуже вращающихся лидаров из-за non-repetitive паттерна: за короткое накопление облако разреженное. Накапливать дольше при статичной сцене.
- 0.5° ошибки attitude на 125 м AGL — это ~1 м смещения патча. При бюджете фикса 3–6 м это заметная доля. Не экономить на точности здесь.
