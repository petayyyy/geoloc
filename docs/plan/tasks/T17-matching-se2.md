## Цель

Из дескрипторов патча и окна карты получить оценку SE(2) — `Δx, Δy, Δψ` — вместе с полным набором метрик качества.

Узел **всегда выдаёт результат** с метриками и **никогда** не решает, годен ли он. Решение изолировано в T22. Это разделение делает integrity-логику независимо тестируемой и заменяемой — а она главный предохранитель системы.

## Что реализовать

1. **Запрос окна карты** у `geoloc_map` по приорному положению и радиусу `R = 3·√(σ_e² + σ_n²) + margin`.
2. **Матчинг дескрипторов:** взаимная ближайшая пара (mutual NN) с отношением расстояний (Lowe ratio). Реализация под int8-дескрипторы на NEON либо на GPU — не наивный O(N·M) на скалярах.
3. **Оценка SE(2) через MAGSAC++:** параметры `Δx, Δy, Δψ`. Масштаб **не оценивать** — он известен из AGL и DSM.
   - Обоснование: для надирного вида на near-planar сцену полная гомография переопределена и неустойчива при малом числе инлаеров; OrthoLoC показывает деградацию PnP при covisibility <20% и вскрывает f–t_z ambiguity.
   - Опционально: 4-DoF с масштабом как диагностика — если оценённый масштаб сильно расходится с известным, это признак плохого матча (полезный сигнал для T22).
4. **Взвешивание по уверенности DSM.** Корреспонденции в зоне Copernicus DEM получают меньший вес, чем в лидарной зоне.
5. **Расчёт всех метрик качества** из `../03-interfaces.md` §1.2: `n_inliers`, `inlier_ratio`, `covisibility`, `peak_ratio`, `residual_rms_px`, `spatial_spread`, `mean_confidence`.
6. **Арбитраж каналов:** основной XFeat; при провале двух кадров подряд — резерв 1 (T19), затем резерв 2 (T20). Стратегия «основной → резерв при провале», не «все параллельно» — экономия бюджета.
7. **Многогипотезный режим** при большом R (холодный старт, LOST): несколько локальных максимумов, ранжирование, публикация лучшей с честным `peak_ratio`.

## Definition of Done

- [ ] Матчинг + MAGSAC за ≤25 мс суммарно на плате
- [ ] Все метрики качества из контракта заполняются корректно
- [ ] `covisibility` считается только по зоне высокой уверенности DSM
- [ ] `peak_ratio` вычисляется осмысленно (вторая по счёту гипотеза, а не второй инлаер)
- [ ] Арбитраж каналов работает, переключение логируется
- [ ] Многогипотезный режим работает при R до 500 м
- [ ] На `regression`: `A@20` ≥ 60%

## Подводные камни

- **`peak_ratio` — важнейшая метрика для integrity, и её легко посчитать неправильно.** Это отношение качества **лучшей гипотезы к второй по счёту, пространственно отделённой** гипотезе, а не отношение расстояний первых двух дескрипторов. На периодических структурах именно она — единственный признак, отличающий верный матч от сдвинутого на период.
- Наивный матчинг дескрипторов 2000 × 8000 на скалярах займёт сотни миллисекунд. NEON int8 dot product или GPU обязательны.
- Не оценивать масштаб «на всякий случай» — это добавит степень свободы, которая на near-planar сцене вырождена и утянет за собой остальные параметры.
- `covisibility` по всей площади патча, включая DEM-зону, даст завышенную оценку. Считать только по зоне высокой уверенности — это прямо влияет на гейт ≥20%.
