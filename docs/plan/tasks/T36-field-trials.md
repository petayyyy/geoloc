# T36 — Программа наземных и лётных испытаний

| | |
|---|---|
| Трек | FIELD |
| Волна | W7 |
| Зависит от | все |
| Блокирует | — |
| Оценка | 15 дней |
| Риск | **высокий** |
| Роль | Все роли, координация |
| Промт | `../prompts/P6-autopilot.md` + общий |

## Цель

Подтвердить работоспособность системы в поле с постепенным наращиванием риска.

## Условие допуска к испытаниям

Не начинать, пока не выполнено **всё** из списка:

- [ ] Все блокирующие сценарии Isaac пройдены, включая **S-04 и S-05**
- [ ] КТ-4 пройдена: реалтайм на плате, латентность p95 ≤300 мс, FAST-LIVO2 ≥10 Гц, T ≤80 °C
- [ ] T35 завершена, калибровка держится после прогона моторов
- [ ] T27 завершена, failsafe согласован с PX4
- [ ] Предполётная проверка (T27) работает и ловит несоответствие карты

## Этапы с эскалацией

### Э1. Наземные (2 дня)

Аппарат на земле, система работает, оператор ходит с аппаратом по площадке.

| Проверка | Критерий |
|---|---|
| Стек поднимается, все узлы живы | ≤30 с от подачи питания |
| Предполётная проверка проходит | Карта, калибровка, версии совпадают |
| Фиксы получаются на площадке | Хотя бы единичные (высота мала, ожидания низкие) |
| Термика на земле без обдува | Не перегревается за 20 мин |
| Телеметрия и сообщения оператору | Читаются, не спамят |

### Э2. Привязные (2 дня)

Аппарат на привязи, подъём до 10–20 м.

| Проверка | Критерий |
|---|---|
| Вибрация в полёте | Спектр в допуске, калибровка держится |
| FAST-LIVO2 в полёте | Такт ≥10 Гц, одометрия адекватна |
| `GPS_INPUT` принимается PX4 | Виден в ulog, EKF2 не ругается |
| Failsafe при отключении geoloc | PX4 ведёт себя как задокументировано |

### Э3. Первый полёт, GNSS активен (2 дня)

**GNSS работает и является источником для EKF2.** Наша система работает параллельно, только пишет логи. Полёт 500 м на 100 м AGL.

| Проверка | Критерий |
|---|---|
| Фиксы получаются на рабочей высоте | `acceptance_rate` в ожидаемом диапазоне для класса местности |
| Ошибка фиксов против GNSS | p50 ≤15 м, p95 ≤40 м |
| Курсовая ошибка | p95 ≤2.5° |
| `IFR` против GNSS-эталона | **< 0.5%** |
| Термика в полёте | T ≤80 °C |

> Это ключевой этап: первое сравнение с реальностью. Если `IFR` здесь окажется выше цели — **возврат к T22, а не продолжение программы**.

### Э4. Полёты с эмуляцией отказа GNSS (4 дня)

GNSS физически работает и пишется как эталон, но для EKF2 отключён — источником становится наш `GPS_INPUT`. Оператор в готовности вернуть GNSS.

| Полёт | Дистанция | Проверка |
|---|---|---|
| П1 | 1 км | Сходимость курса, ≥5 фиксов на 2 км (пересчёт на дистанцию) |
| П2 | 2 км | КТ-2 в поле |
| П3 | 5 км, смешанная местность | ATE ≤15 м, разбивка по классам |
| П4 | 5 км с участком над однородной местностью | COASTING и восстановление |

### Э5. Полный маршрут (3 дня)

| Полёт | Проверка |
|---|---|
| 10 км по коридору | **КТ-6: ошибка p95 ≤30 м против GNSS-эталона** |
| Повтор в других условиях освещения | Устойчивость |
| Повтор с холодным стартом | TTFF ≤10 с в поле |

### Э6. Разбор и документирование (2 дня)

Сводный отчёт, сравнение полевых метрик с прогнозом уровней A/B/E, обновление golden runs, список расхождений между симуляцией и реальностью.

## Definition of Done

- [ ] Все этапы пройдены с зафиксированными результатами
- [ ] **КТ-6: на 10 км ошибка p95 ≤30 м, `IFR` <0.5%**
- [ ] Полевые метрики сопоставлены с прогнозом уровней A/B/E, расхождения объяснены
- [ ] Все полёты залогированы, логи сохранены
- [ ] Отчёт с рекомендациями по дальнейшей работе

## Правила безопасности

| Правило | |
|---|---|
| GNSS всегда физически работает и пишется как эталон | Даже когда отключён для EKF2 |
| Оператор в готовности вернуть GNSS в любой момент | Отдельный переключатель, проверенный на земле |
| Не переходить к следующему этапу при незакрытых замечаниях предыдущего | Без исключений |
| Первый полёт каждого этапа — в наиболее благоприятных условиях | Хорошее освещение, текстурированная местность, слабый ветер |
| При любом неожиданном поведении — прекращение и разбор | Не «попробуем ещё раз» |

## Подводные камни

- **Поле всегда отличается от симуляции.** Расхождение прогноза и реальности — не провал, а ожидаемый результат, который надо измерить и объяснить. Этап Э6 существует ровно для этого.
- **Соблазн пропустить этап.** Э3 (с работающим GNSS) кажется формальностью, когда всё прошло в симуляции. Это единственный этап, где ошибка ничего не стоит, — и потому самый ценный.
- **`IFR` в поле почти наверняка окажется выше, чем в симуляции.** Реальность богаче на ловушки, чем набор `adversarial`. Заложить время на возврат к T22 после Э3.
- Погода и освещение — неконтролируемые переменные. Логировать условия каждого полёта, иначе результаты несопоставимы между днями.
