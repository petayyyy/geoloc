Создать структуру репозитория и ROS 2 workspace, в которых будут работать все остальные задачи. Зафиксировать соглашения, чтобы шесть параллельных потоков не разошлись.

## Ключевые решения

| Решение | Значение | Обоснование |
|---|---|---|
| Язык узлов | C++17 для всего, что в реальном контуре; Python для инструментов | Бюджет RK3588 не терпит Python в контуре |
| ROS | Зафиксировать Humble или Jazzy в [ADR-007](../adr/ADR-007-ros-distro-os.md) — **открыт, закрыть до старта** | Определяется доступностью arm64-пакетов под выбранную ОС |
| Сборка | `colcon`, `ament_cmake` | Стандарт |
| Стиль | `clang-format` (Google, 100 колонок), `ruff` + `black` для Python | |
| Геометрия | Eigen 3.4 везде. Собственных матричных типов не заводить | |
| Логирование | `rclcpp` logger + структурированные метрики отдельным каналом | |
| Ветвление | trunk-based, короткоживущие ветки, обязательный PR | 6 параллельных потоков — long-lived branches убьют проект |

## Что реализовать

1. Пакет `geoloc_msgs` со **всеми** сообщениями из `03-interfaces.md` — целиком, сразу. Параллельные потоки должны иметь стабильный контракт с первого дня.
2. Пакет `geoloc_common`:
   - `geodetic.hpp` — WGS84 ↔ локальный ENU через опорную точку;
   - `se2.hpp` — композиция, инверсия, нормализация угла, ковариации;
   - `raster.hpp` — пиксель ↔ ENU для геопривязанного растра;
   - `covariance.hpp` — проверка положительной определённости, симметризация.
3. Скелеты остальных пакетов: узел публикует пустые сообщения, launch-файл поднимает граф целиком. **Граф должен запускаться в первый же день**, пусть и без содержания.
4. `configs/mission_template.yaml` со всеми параметрами и порогами из `01-requirements.md` и `05-metrics.md`.
5. `pre-commit`: формат, линт, проверка отсутствия `TODO` без номера задачи.

## Definition of Done

- [ ] `colcon build` проходит с нуля на x86 без предупреждений
- [ ] `ros2 launch geoloc_bringup all.launch.py` поднимает все узлы, `ros2 topic list` показывает все топики из `03-interfaces.md`
- [ ] `geoloc_common` покрыт тестами ≥90%
- [ ] `pre-commit run --all-files` чист
- [ ] README с инструкцией на 10 строк: как собрать, как запустить, где конфиг

## Тесты

| ID | Уровень | Что проверяет | Критерий |
|---|---|---|---|
| T01-U-01 | 0 | Round-trip WGS84 ↔ ENU | Ошибка < 1e-6 м на расстоянии до 20 км от опорной точки |
| T01-U-02 | 0 (property) | Композиция и инверсия SE(2) | `a * a⁻¹ = I` с точностью 1e-12; ассоциативность |
| T01-U-03 | 0 (property) | Нормализация угла | Результат всегда в `[-π, π]`, эквивалентен входу по mod 2π |
| T01-U-04 | 0 | Пиксель ↔ ENU для растра | Round-trip < 1e-9 px; корректность на границах |
| T01-U-05 | 0 | Ковариация: симметризация и проверка ПО | Несимметричная матрица чинится; неположительно определённая отвергается |
| T01-I-01 | 0 | Граф поднимается | Все узлы живы 30 с, все топики публикуются |

## Подводные камни

- **Не откладывать `geoloc_msgs`.** Если контракт сообщений появится на второй неделе, шесть потоков успеют написать шесть несовместимых структур.
- Нормализация угла — источник половины багов в SE(2)-системах. Property-тест обязателен, не «на глаз».
- ENU-опорная точка должна быть **параметром миссии**, а не константой в коде.
