# 05 — Метрики и пороги

Единый словарь. Все уровни считают метрики **одинаково** — иначе цифры несопоставимы.

---

## 1. Метрики уровня фикса

| Метрика | Определение | Порог | Авторитетный уровень |
|---|---|---|---|
| `A@d` | Доля фиксов с ошибкой положения ≤ d м, среди **принятых** | A@5 ≥15%, A@10 ≥35%, A@20 ≥60%, A@50 ≥85% (город/пригород) | B |
| `RE_med`, `RE_p95` | Ошибка курса фикса, медиана и p95 | ≤1.0° / ≤2.5° | B |
| `n_inliers` | Инлаеры MAGSAC | ≥30 для принятия | — |
| `inlier_ratio` | Инлаеры / соответствия | ≥0.25 для принятия | — |
| `covisibility` | Доля площади патча, покрытая инлаерами | ≥0.20 (гейт, из OrthoLoC) | — |
| `peak_ratio` | Лучшая гипотеза / вторая по счёту | ≥1.3 для принятия | — |
| `residual_rms_px` | RMS остатка инлаеров | ≤2.0 px | — |
| `spatial_spread` | Равномерность распределения инлаеров (энтропия по квадрантам, норм. 0..1) | ≥0.4 | — |
| **`IFR`** | **Integrity Failure Rate**: доля принятых фиксов с ошибкой >50 м | **< 0.5%** | B, подтв. E |
| `acceptance_rate` | Принятые / все попытки | город ≥60%, пригород ≥50%, поля ≥25%, лес ≥8% | B |
| `latency_ms` | Кадр → публикация `/geoloc/fix` | p95 ≤300 мс | B (`target=rk3588`) |

> `IFR` — **главная метрика проекта.** Она стоит выше точности: система, которая честно молчит, безопасна; система, которая уверенно врёт, теряет аппарат. Все компромиссы разрешаются в её пользу.

## 2. Метрики уровня траектории

| Метрика | Определение | Порог | Уровень |
|---|---|---|---|
| `ATE_RMSE` | RMSE ошибки положения по всей траектории | ≤15 м на 5–10 км | B, E |
| `lateral_p95` | p95 бокового (поперёк курса) ухода | ≤30 м | B |
| `yaw_error_converged_p95` | p95 курсовой ошибки после сходимости | ≤0.5° | B |
| `convergence_distance` | Путь до σ_ψ < 1° от старта с ±3° | ≤2 км | B |
| `fixes_per_2km_initial` | Валидных фиксов на первых 2 км | **≥5** | B |
| `fixes_per_km` | Средняя плотность фиксов | ≥2 (город), ≥0.5 (смешанная) | B |
| `TTFF` | Time to first fix при приоре ±500 м | ≤10 с | B, E |
| `max_gap_distance` | Макс. путь между валидными фиксами | ≤3 км | B |
| `recovery_time` | Время до возврата в NOMINAL после 2-км аутэйджа | ≤30 с | E |
| `mode_nominal_fraction` | Доля времени в режиме NOMINAL | ≥90% (город/смешанная) | B, E |

## 3. Метрики состоятельности оценки

Считаются на Monte-Carlo наборе (≥100 сидов). Проверяют **честность ковариации**, а не точность.

| Метрика | Определение | Критерий |
|---|---|---|
| `NEES` | Нормализованная квадратичная ошибка оценки, усреднённая по прогонам | Средняя внутри 95% ДИ χ² по DoF |
| `NIS` | Нормализованная инновация по последовательности фиксов | То же |
| `sigma1_coverage` | Доля времени, когда истинная ошибка внутри 1σ | 60–75% (теория 68%) |
| `sigma3_coverage` | То же для 3σ | ≥99% |
| `cov_monotonicity` | В режиме COASTING ковариация растёт монотонно | обязательно |

> Если `NEES` вылетает — **чинить T21 (модель ковариации)**, а не подкручивать константы в `geoloc_mavlink`. Нечестная ковариация приводит к нечестному `eph`, а от него напрямую зависит, поверит ли EKF2 фиксу. Это самая частая причина провала КТ-3.

## 5. Разбивка по классам местности

Все метрики фиксов **обязательно** приводятся с разбивкой. Средняя по всем классам цифра вводит в заблуждение: она смешивает город, где всё работает, и лес, где не работает ничего.

| Класс | Как определяется | Целевой `acceptance_rate` | Целевой `A@20` |
|---|---|---|---|
| Город | Растр OSM: доля `building` > 15% | ≥60% | ≥75% |
| Пригород / застройка | 3–15% | ≥50% | ≥70% |
| Дороги, инфраструктура | `road` > 5%, `building` < 3% | ≥40% | ≥65% |
| Пашня / поля | `farmland` > 60% | ≥25% | ≥55% |
| Лес | `forest` > 60% | ≥8% | ≥40% |
| Вода | `water` > 50% | — (ожидается отказ) | — |

Для класса «вода» проверяется **не точность, а корректность отказа**: `IFR` на нём должен быть 0.

## 7. Golden runs и допуски

| Правило | Значение |
|---|---|
| Golden-наборы | A: `regression`, `adversarial`. B: `micro` (3×500 м) |
| Допуск на деградацию | **5%** относительно golden по любой ключевой метрике → CI падает |
| Ключевые метрики | `A@20`, `RE_p95`, `IFR`, `acceptance_rate`, `latency_p95` |
| `IFR` — особый случай | Ужесточённый допуск: рост более чем на **0.1 п.п.** → CI падает независимо от относительного изменения |
| Обновление golden | Только явным коммитом с обоснованием в описании PR. Автообновление **запрещено** |
